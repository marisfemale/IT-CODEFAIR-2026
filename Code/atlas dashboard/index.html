How scoring and comparison work

For each factor, normalised value = (value − minimum) / (maximum − minimum). Priority score = sum of normalised value × factor weight. Every factor increases priority as its value increases. A score is an index, not a percentage without coverage.

Ranges are fixed to the full community set in each uploaded model. Adjusting weights does not recalculate entropy. Ranking 1 contains 792 communities; Ranking 2 includes the 468 with recorded population. The 324 missing-population communities are excluded from Ranking 2, not assigned zero population.

Models use different populations, weights and normalisation ranges, so their scores are not directly comparable. Population is an independent factor: a large community may rank highly even with both need flags set to 0. Need flags use the uploaded 0/1 values; their exact definitions should be checked against the preparation code.

Equal scores share a rank (for example 1, 1, 3); ties are displayed in community-name order. Calculations use full precision. Displayed percentages and scores are rounded.
